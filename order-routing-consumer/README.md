README – JavaScript File Instructions

Due to Gmail's security policies, files with the .js extensions cannot be sent directly via email.

To comply with these restrictions, the script files in this ZIP archive have been appended with a `.txt` extension. Please follow the instructions below to restore the original filenames.

Rename the following files as:

- truffle-config.js.txt → truffle-config.js
- ./migrations/1_initial_migrations.js.txt -> ./migrations/1_initial_migrations.js

After renaming, this file may be deleted.
