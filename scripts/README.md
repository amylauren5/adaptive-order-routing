README – Shell Script File Instructions

Due to Gmail's security policies, files with the .sh and .js extensions cannot be sent directly via email.

To comply with these restrictions, the script files in this ZIP archive have been appended with a `.txt` extension. Please follow the instructions below to restore the original filenames before executing the scripts.

Rename the following files as:

- baseline-test-run.js.txt → baseline-test-run.js
- chaos-test-run.js.txt    → chaos-test-run.js
- extract-ganache.sh.txt   → extract-ganache.sh
- start.sh.txt             → start.sh
- teardown.sh.txt          → teardown.sh

Once renamed, the scripts can be executed as intended.

After renaming, this file may be deleted.
